## 1. Entity Overview

Não há banco de dados. O "modelo de dados" é um conjunto de **snapshots JSON** commitados (cache determinístico) que tornam a demo reprodutível offline. Cada fonte (`Spotify pessoal`, `Deezer`, `iTunes`) produz uma lista ordenada de **itens**; a posição de cada item é seu **índice 0-based** no array da API. O browser consome um **wrapper** (`window.RANK_SNAPSHOT`) porque `fetch()` de JSON local é bloqueado em `file://` (ver `DECISIONS.md` D1).

## 2. Entities

### Source

### Item (track)
**Tipo:** objeto dentro de `Source.items`

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `key` | `string` | NOT NULL | Chave de matching normalizada `` `${title}|${artist}` `` (§12.2) |
| `title` | `string` | NOT NULL | Título **cru** para exibição |
| `artist` | `string` | NOT NULL | Artista **cru** para exibição |
| `position` | `integer` | ≥ 0 | Índice 0-based no array da API (uniforme entre fontes) |

**Business Rules:**
- `key` é gerada por `RankingConsensusUtils.normalizeKey(title, artist)` (NFD→sem acentos→minúsculas→remove pontuação/sufixos→colapsa espaços; artista = primeiro antes da vírgula).
- **Deduplicação:** mesma `key` na mesma fonte → mantém a **melhor posição** (menor índice) (`dedupeByKey`).
- **Re-rank em interseção:** dentro da interseção de um par, cada fonte é re-indexada pela **ordem relativa** (não a posição original) (§12.3).

### Snapshot (wrapper browser)
**Arquivo:** `data/snapshot.js` (gerado, não editado à mão)


**Regra:** regenerar com `node scripts/build_snapshot.js` **sempre** que os `data/*.json` mudarem. Nunca colocar tokens/segredos no snapshot (modo cache puro).

| Structure | Shape | Rule |

## 5. Soft Deletes

- **Strategy:** **Hard delete** — arquivos JSON são sobrescritos na regeração (não há soft delete).

## 6. Invariants & Thresholds

- `position` sempre 0-based e único por fonte após dedupe.
- Kendall-Tau opera **somente sobre a interseção**; pares com `< 15` itens comuns são **sinalizados** e ficam **fora** da matriz principal ("interseção insuficiente").
- `tau ∈ [-1, 1]`; `n < 2` → `tau = null`.
- Snapshots (`data/*.json` + `data/snapshot.js`) são **commitados** para demo offline.
